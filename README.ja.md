# Xo Beta

[English](README.md)

**ブラウザネイティブのシングルプレイヤー 3D バトルロイヤル。高密度なアリーナに、人間 1 人と自律ボット 9 体の計 10 人が降下し、最後の 1 人になるまで戦います。**

Xo Beta はデスクトップブラウザ上で完全にクライアントサイド動作します。プラグイン、インストール、ゲームプレイサーバーは不要です。表現には、独自のコード生成システムと再配布可能な CC0（パブリックドメイン）のアート・音声パックを組み合わせています。来歴の詳細は [docs/ASSET_MANIFEST.md](docs/ASSET_MANIFEST.md) を参照してください。

---

## 機能

- **完全なマッチ進行** — 輸送機での飛行 → 自由降下 → グライド → 着地 → 物資収集 → ストーム縮小 → 最終サークル → リザルト画面。
- **3 つの手作りアリーナ** — *NEO CITY*（夜のネオン都市）、*OLD FRONT*（大聖堂をランドマークに持つ曇天の歴史的な町）、*EDEN FACILITY*（昼の湖畔研究施設）。
- **高度な移動** — スプリント、しゃがみ、スライディング、ダブルジャンプ、地上・空中ダッシュ、ウォールラン、壁ジャンプ、よじ登り、グラップリングフック、グラウンドパウンド、バニーホップの慣性、水泳、潜水。ボットも同じ移動システムを使います。
- **5 種類の武器クラス** — ピストル（セミオート）、SMG（フルオート）、AR（フルオート）、ショットガン（ポンプアクション）、スナイパー（ボルトアクション）。それぞれに 5 段階のレアリティがあり、飛翔時間、重力落下、距離減衰、跳弾、ショットガンのペレット単位の拡散を含む実弾シミュレーションを行います。
- **公平な AI 対戦相手** — 異なる個性を持つ 9 体のボット（VEX、RAZOR、ORBIT は上位ベンチマークの 3 体）。知覚は視野角、見通し判定、ゲーム内の音イベントだけに基づき、ウォールハックや全知情報は使いません。物資収集、回復、移動、漁夫行動、高度な移動も行います。
- **完全なルート経済** — フロアルート、3 段階の宝箱（標準／エリート／保管庫）、医療キット、シールドセル、5 つの共通インベントリスロット、弾薬プール。
- **磨き込まれた表現** — PBR マテリアル、マップごとの動的ライティング、ブルーム、弾道・マズルフラッシュ・着弾・破片、流血を伴わないスタイライズされた撃破エフェクト、空間化された CC0 効果音、環境音、独自のメニュー／リザルト音。

## ブラウザ基準

現行のデスクトップ版 Chrome と Edge をリリーステストの基準としています。ほかの最新 WebGL2 ブラウザでも動作する可能性はありますが、リリース検証済みとはしていません。キーボードとマウスを備えたデスクトップブラウザが必要で、タッチ端末には未対応入力であることを明示します。

## 開発

```bash
npm ci
npm run dev          # Vite 開発サーバー: http://localhost:5173
```

```bash
npm run build        # 型検査 + dist/ への本番ビルド
npm run preview      # 本番ビルドをローカル配信
npm run test         # 単体 + 統合テスト（Vitest）
npm run sim -- map=neocity difficulty=hard count=3   # ヘッドレスのボットマッチ
npm run audit:assets                 # 本番アセット集合 + SHA-256
npm run audit:secrets                # 追跡対象／無視対象外ソースのスキャン
npm run audit:licenses               # 依存ライセンス方針の検査
npm run cloudflare:dry-run           # ビルド + Wrangler 検証（アップロードなし）
npx tsx tests/browser/qa-maps.ts     # 任意のローカルブラウザ QA（Playwright）
```

アーキテクチャの概要は [開発ガイド](docs/DEVELOPMENT.md)、テスト方針の詳細は [テスト戦略](docs/TESTING.md) を参照してください。

## Cloudflare へのデプロイ

本番ビルドは [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/) を使う Cloudflare Worker から静的バンドルとして配信します。

```bash
npm run build
npx wrangler deploy      # wrangler.jsonc を使用
```

詳細は [デプロイガイド](docs/DEPLOYMENT.md) を参照してください。

## アーキテクチャ概要

固定タイムステップのマッチシミュレーション（`src/sim`）を、描画（`src/render`）、音声（`src/audio`）、UI（`src/ui`）、入力（`src/player`）から完全に分離したシミュレーション優先設計です。人間とボット（`src/ai`）のコントローラーはいずれも `InputCommand` を生成するため、ボットはプレイヤーとまったく同じルールで動きます。物理演算は Rapier（WASM）、ナビゲーションはジャンプ／よじ登り／落下／水泳リンクを持つ生成済みの多層ナビグラフ、コンテンツはマップ定義からデータ駆動で構築されます。詳細は [アーキテクチャ](docs/ARCHITECTURE.md)、[ボット AI](docs/BOT_AI.md)、[ゲームデザイン](docs/GAME_DESIGN.md) を参照してください。
